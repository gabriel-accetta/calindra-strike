# Dust2 geometry

`shared/src/maps/dust2.geometry.json` was converted from the CS 1.6
`de_dust2.rmf` file at https://temaps.com/files/goldsrc/rmf-maps/de-dust2.
Download: https://temaps.com/files/goldsrc/rmf-maps/de_dust2.rmf
Source SHA256: `7623a7310bb9383403af757c30fda07b375081d6a796846a1062f36b5bc8614b`.

The map is credited to its original Counter-Strike authors (Dust II: David
Johnston). This is third-party map geometry, not original Calindra artwork;
no new license or ownership claim is made over it. The MIT license on the
unimator repository does not apply to this separately obtained source.

Regenerate with Python's standard library:

```bash
python3 tools/maps/import-dust2.py /path/to/de_dust2.rmf
```

The conversion preserves convex brush faces, ramps and door openings, maps
GoldSrc Z-up coordinates to Y-up, and raises the lowest floor to zero.
Sky volumes and solid gameplay triggers are omitted for parachute spawns.
Original team spawn coordinates and bombsite trigger bounds are preserved in
`dust2.objectives.json` for the optional defuse mode. Static
breakables remain solid; illusionary decorations are visual only. Materials
are generated by the existing renderer, rather than importing Valve WADs.
The import is geometry only: original lighting, decals and textures are absent.
Player collisions expand brush planes by the axis-aligned player hull; this
can be conservative at corners of non-axial brushes.

Use `GAME_MAP=dust2 npm run dev:server` locally, or `GAME_MAP=dust2` in the
server `.env` with Docker Compose. An empty `GAME_MAP` includes Dust2 in the
normal rotation, in both TDM and FFA.
